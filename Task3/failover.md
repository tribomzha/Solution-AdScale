# RPO и RTO для каждого сервиса, стратегию резервного копирования

| **Сервис**        | RPO    | RTO     | Стратегии резервного копирования |
| ----------------- | ------ | ------- | -------------------------------- |
| Сервис ставок     | 5 мин  | 2 сек   | Incremental (каждые 5 минут)     |
| Сервис кампаний   | 5 мин  | 5 мин   | Incremental (каждые 5 минут)     |
| Сервис статистики | 7 дней | 72 часа | Full Backup                      |
| Сервис аналитики  | 7 дней | 72 часа | Full Backup                      |
| Сервис финансов   | 1 мс   | 2 сек   | Incremental (каждые 5 минут)     |


# Общая оценки соответствия принципам 12-факторных приложений

| параметр                                     | Соответствие/не соответствие                                |
| -------------------------------------------- | ----------------------------------------------------------- |
| кодовая база                                 | не соответствует - для каждой среды свой патч               |
| зависимости                                  | соответствует                                               |
| конфигурации                                 | не соответствует - конфиг в файле                           |
| сторонние службы                             | соответствует                                               |
| сборка и запуск                              | не соответствует - сборка под каждую среду                  |
| процессы                                     | соответствует                                               |
| привязка портов                              | соответствует                                               |
| параллелизм                                  | соответствует                                               |
| расположение данных                          | соответствует                                               |
| утилизируемость                              | соответствует                                               |
| ведение логов                                | соответствует                                               |
| администрирование                            | соответствует                                               |
| среды разработки, тестирования, эксплуатации | не соответствует - разные сборки, а значит разные артефакты |
