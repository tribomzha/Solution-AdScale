| **Сервис**        | **Тип базы данных** | **старатегия масштабирования**                                                           |
| ----------------- | ------------------- | ---------------------------------------------------------------------------------------- |
| Сервис ставок     | postgres            | репликация Master-Slave с read replicas<br>Требуется CQRS                                |
| Сервис кампаний   | postgres            | геораспределенное шардирование,репликация Master-Slave с read replicas<br>Требуется CQRS |
| Сервис статистики | clickHouse          | Master-Slave для сохранности данных                                                      |
| Сервис аналитики  | postgres            | репликация не требуется, т.к. отчеты можно пересобрать                                   |
| Сервис финансов   | postgres            | Master-Slave для сохранности данных<br>Требуется CQRS                                    |
