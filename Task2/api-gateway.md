# Граница ответственности

| API Gateway отвечает                | API Gateway не отвечает           |
| ----------------------------------- | --------------------------------- |
| Приём запросов внешних DSP          | Определение рекламных кандидатов  |
| Идентификация DSP                   | Проверка таргетинга кампаний      |
| Аутентификация и авторизация        | Расчёт ставки                     |
| Проверка формата запроса            | Выбор рекламного материала        |
| Защита от повторных запросов        | Проведение аукциона               |
| Ограничение RPS и конкурентности    | Проверка бюджета кампании         |
| Маршрутизация во внутренние сервисы | Формирование бизнес-решения       |
| Контроль времени обработки          | Хранение профиля пользователя     |
| Circuit Breaker внутренних сервисов | Бизнес-логика DSP                 |
| Технический аудит и мониторинг      | Аналитика рекламной эффективности |


# Endpoints

| Endpoint                     | Потребитель         | Назначение                                 |
| ---------------------------- | ------------------- | ------------------------------------------ |
| POST /api/v1/bid-requests    | Внешняя DSP         | Отправка запроса ставки                    |
| GET /api/v1/capabilities     | Внешняя DSP         | Получение поддерживаемых версий и форматов |
| GET /health/ready            | Балансировщик       | Проверка готовности принимать запросы      |
| GET /metrics                 | Система мониторинга | Получение метрик                           |
| GET /internal/config/version | Эксплуатация        | Просмотр версии конфигурации               |
| POST /internal/routes/drain  | Эксплуатация        | Вывод внутреннего маршрута из работы       |

#Основной сценарий

| Шаг | Действие                                                        |
| --: | --------------------------------------------------------------- |
|   1 | DSP отправляет запрос ставки в нашу систему                     |
|   2 | API Gateway устанавливает TLS/mTLS-соединение                   |
|   3 | API Gateway идентифицирует внешнюю DSP                          |
|   4 | API Gateway проверяет право DSP выполнять запрос                |
|   5 | API Gateway проверяет размер и формат тела                      |
|   6 | API Gateway валидирует внешний контракт                         |
|   7 | API Gateway преобразует запрос во внутренний формат             |
|   8 | API Gateway проверяет уникальность request ID                   |
|   9 | API Gateway применяет rate limit и concurrency limit            |
|  10 | API Gateway рассчитывает deadline                               |
|  11 | API Gateway выбирает внутренний маршрут                         |
|  12 | API Gateway проверяет состояние Circuit Breaker                 |
|  13 | API Gateway вызывает внутренний сервис обработки запроса ставки |
|  14 | API Gateway обрабатывает запрос и формирует ответ               |
|  15 | API Gateway проверяет и адаптирует ответ                        |
|  16 | API Gateway возвращает результат внешней DSP                    |
|  17 | API Gateway записывает метрики, trace и audit-события           |

#Альтернативные сценарии
|№|Сценарий|Поведение API Gateway|Ответ DSP|
|--:|---|---|--:|
|1|DSP успешно получила ставку|Gateway передаёт корректный ответ внутреннего сервиса|`200`|
|2|Наша система не сформировала ставку|Gateway возвращает no-bid в контрактном формате|`200` с пустым результатом или `204`|
|3|DSP не аутентифицирована|Запрос блокируется до бизнес-обработки|`401` или TLS error|
|4|DSP аутентифицирована, но не имеет права на операцию|Gateway проверяет разрешения и запрещает вызов|`403`|
|5|DSP временно отключена|Конфигурация DSP содержит статус `SUSPENDED`|`403`|
|6|Некорректный JSON|Запрос не передаётся во внутренний сервис|`400`|
|7|Некорректная структура запроса|Gateway возвращает список допустимых технических ошибок|`400/422`|
|8|Размер запроса превышен|Gateway прекращает чтение тела|`413`|
|9|Превышен RPS DSP|Token bucket не выдаёт разрешение|`429`|
|10|Превышено число in-flight запросов DSP|Новый запрос не ставится в длинную очередь|`429/503`|
|11|Перегружена вся наша система|Admission Controller включает load shedding|`503`|
|12|Повторён тот же request ID|Возвращается сохранённый ответ или признак дубликата|`200` или `409`|
|13|Один request ID используется с разным телом|Gateway считает запрос конфликтующим|`409`|
|14|Не поддерживается версия API|Gateway не может подобрать адаптер|`400/426`|
|15|Не поддерживается тип рекламного запроса|Запрос не передаётся в бизнес-сервис|`422` или no-bid|
|16|Основной backend недоступен|Gateway использует резервный маршрут|`200`, `204` или `503`|
|17|Circuit Breaker открыт|Вызов backend не выполняется|`503`|
|18|Внутренний сервис отвечает слишком долго|Upstream Client отменяет вызов по deadline|`504`|
|19|Внутренний сервис вернул `5xx`|Ошибка маскируется стабильным публичным контрактом|`502/503`|
|20|Внутренний сервис вернул некорректный ответ|Gateway блокирует повреждённый результат|`502`|
|21|Ответ сформирован после deadline|Результат не отправляется как действующая ставка|`504` или no-bid|
|22|Control plane недоступен|Gateway работает на последней валидной конфигурации|Обычный ответ|
|23|Сервис мониторинга недоступен|Обработка запросов продолжается|Обычный ответ|

№Конфигурация AGW

| Параметр           | Назначение                         | Пример                 |
| ------------------ | ---------------------------------- | ---------------------- |
| dspId              | Уникальный идентификатор DSP       | dsp-001                |
| status             | Статус интеграции                  | ACTIVE                 |
| authenticationType | Способ аутентификации              | MTLS                   |
| allowedApiVersion  | Допустимые версии API              | v1, v2                 |
| allowedOperations  | Разрешённые операции               | BID_REQUEST            |
| allowedFormats     | Допустимые форматы рекламы         | banner, video          |
| sustainedRps       | Постоянный лимит запросов          | 18 000                 |
| burstRps           | Допустимый кратковременный всплеск | 25 000                 |
| maxInflight        | Максимальная конкурентность        | 5 000                  |
| defaultTimeoutMs   | Стандартное время ответа           | 100                    |
| maxTimeoutMs       | Максимально допустимый timeout     | 300                    |
| primaryRoute       | Основной внутренний маршрут        | bid-request-service-v2 |
| fallbackRoute      | Резервный маршрут                  | bid-request-service-v1 |
| duplicateTtlMs     | Период защиты от повторов          | 5 000                  |
| noBidResponseMode  | Формат отсутствия ставки           | HTTP_204               |
| maskInternalErrors | Скрывать внутренние детали         | true                   |
